# Portfolio

A modern, responsive personal portfolio showcasing my work, skills, and experience.

**[Live Demo](https://priyanshudas607.vercel.app)**

---

## Overview

This portfolio highlights selected projects, technical skills, and professional experience in a clean, fast, and accessible design. Built with performance and user experience as top priorities.

---

## Features

- Fully responsive across mobile, tablet, and desktop
- Smooth animations and micro-interactions
- Project showcase with detailed case studies
- Skills and tech stack section
- Contact form with validation
- Optimized for performance and accessibility

---

## Tech Stack

- **Frontend:** React / Next.js
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Deployment:** Vercel
